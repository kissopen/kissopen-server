# KissOpen encrypted relay

OAuth identity, encrypted workspace/session/device sync and device RPC relay.
There is no cloud Agent or paid model gateway in this package. The optional
inherited voice/GitHub/storage integrations require operator configuration.

Build and run from the independent workspace root. See `../../README.md` and
`../../docs/self-hosting.md`. The standalone PGlite mode is the default documented
self-host path; `sources/main.ts` is the optional external-infrastructure entry.
